## 2. Learning Methodologies

### Technical Knowledge Assessment (Socratic Method)

```c
You are my Socratic tutor.  
Your task is to teach me by asking progressively harder and deeper questions about [TOPIC].  
Rules:
- Start with basic questions to assess my level.
- If I answer correctly, increase the difficulty of the next question.
- If I struggle, ask a simpler guiding question to help me think.
- Do not explain the answer unless I explicitly ask for a hint or explanation.
- Keep questions clear and focused (one idea at a time).
- Continue questioning until I say "stop."
```

### Coding Questions (REACTO Framework)

- R: Repeat the problem in your own words
- E: Write examples/use cases
- A: Approach - discuss your solution approach
- C: Code - implement your solution
- T: Test - verify your solution works
- O: Optimize - improve your solution

### Behavioral Questions (STAR Framework)

- S: Situation - describe the context
- T: Task - explain what needed to be done
- A: Action - detail what you did
- R: Result - share the outcomes

### System Design Questions

1. Requirements gathering
2. High-level design
3. Component breakdown
4. Detailed design
5. Trade-offs analysis

## 3. Learning from Mistakes

### Socratic Review Process

When you encounter a question you couldn't answer or struggled with:

1. **Initial Assessment**
   - Add the question to the "Questions to Review Later" table
   - Note the specific areas where you struggled

2. **Socratic Learning Session**

   ```
   You are my Socratic tutor for learning from mistakes.
   Rules:
   - Start by asking me to explain my initial approach
   - Identify gaps in my understanding
   - Ask progressively simpler questions to find the root cause
   - Focus on fundamental concepts I might have missed
   - Guide me to discover the correct approach
   - Continue until I can explain the solution confidently
   ```

3. **Progress Tracking**
   - Update the Memory Bank with new learnings
   - Mark the question as "Under Review" in the tracking table
   - Set a review date to test understanding again

4. **Knowledge Gap Analysis**

   | Topic | Missing Fundamentals | Learning Resources | Review Status |

   |       |                     |                   |               |

5. **Follow-up Process**
   - After Socratic learning, attempt similar questions
   - Document successful applications of new knowledge
   - Update understanding levels in the Memory Bank

## 5. Best Practices

1. Be honest about your knowledge level
2. Take notes during AI interactions
3. Review challenging questions regularly
4. Practice explaining your thought process
5. Use the frameworks consistently to build muscle memory

## 6. AI Interaction Guidelines

1. Always specify which framework you want to use (Socratic, REACTO, or STAR)
2. For technical topics, start with the Socratic method
3. For coding questions, explicitly request REACTO guidance
4. For behavioral questions, use the STAR framework
5. If you struggle with a question, add it to the "Questions to Review Later" table
6. Request step-by-step guidance for each framework to build consistent habits
